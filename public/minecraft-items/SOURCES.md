# Minecraft Item Texture Sources

Item, block, and shield entity texture PNGs in this folder were downloaded from the Minecraft 1.20.1 assets mirror:

https://github.com/InventivetalentDev/minecraft-assets/tree/1.20.1/assets/minecraft/textures

The site uses these textures only as item sprites for the event shop UI and does not include Minecraft, Mojang, Microsoft, or other official logos.

`shield.png` is a small inventory-style sprite drawn for this UI, because the Java shield is rendered from an entity/model texture rather than a regular 16x16 item texture in the source assets.

Spawn egg sprites are rendered from the Minecraft 1.20.1 `spawn_egg.png` and `spawn_egg_overlay.png` item textures with the Java Edition mob egg tint colors. `netherite_upgrade_smithing_template.png` is the vanilla Minecraft 1.20.1 item texture.
