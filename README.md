# Магазин речей та наборів

Next.js-магазин для Minecraft-сервера з внутрішньою валютою "талери". Гравці можуть поповнювати баланс, додавати ресурси й набори в кошик, оформлювати покупки та відстежувати статус видачі в особистому кабінеті.

## Основні Можливості

- Каталог активних товарів: набори, шалкери, ресурси й суперпредмети.
- Кошик для кількох товарів в одному замовленні.
- Поповнення балансу талерів із ручним підтвердженням адміністратором.
- Особистий кабінет із балансом, історією покупок і статусами видачі.
- Адмін-панель для товарів, замовлень, користувачів, поповнень і команд видачі.
- Email-коди для реєстрації та входу адміністратора.
- Discord/webhook-повідомлення про нові замовлення.

## Запуск

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

Локально сайт відкривається на `http://localhost:3000`.

## Корисні Скрипти

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run db:push
npm run db:seed
```

## Налаштування

Приклад змінних середовища лежить у `.env.example`. Для роботи потрібна база PostgreSQL, `DATABASE_URL`, `DIRECT_URL`, секрети авторизації та, за потреби, SMTP/webhook/Monobank-налаштування.

## Товари

Seed створює базові категорії:

- стартові набори;
- набори виживання;
- бойові набори;
- суперпредмети;
- окремі ресурси.

Публічна вітрина показує активні загальні товари. Старі командні або сервісні позиції не потрапляють у каталог і не приймаються API оформлення замовлення.
